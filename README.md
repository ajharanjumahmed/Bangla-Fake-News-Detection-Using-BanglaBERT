# Bangla Fake News Detection using Transformer-based Models 📰🤖

This repository contains an **Artificial Intelligence–based fake news detection system** designed specifically for **Bangla news articles**. The project leverages **state-of-the-art transformer-based NLP models** to classify news content as **real or fake** with high accuracy.

Due to the limited availability of automated misinformation detection tools for low-resource languages, this project aims to contribute toward **combating the spread of fake news in Bangla digital media**.

## Key Features

- Transformer-based model fine-tuned for Bangla text classification
- Comprehensive data preprocessing and tokenization
- Evaluation using **accuracy, precision, recall, and F1-score**
- Jupyter Notebook implementation for easy experimentation and reproducibility
- Focus on **low-resource language NLP (Bangla)**

## Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- Jupyter Notebook

## Use Cases

- Automated fake news detection for Bangla online news portals
- Academic research and experimentation in NLP
- Educational purposes for understanding transformer-based text classification

## Project Overview

The system follows a complete **machine learning pipeline**:  

1. **Data Collection & Preprocessing:** Cleaning and preparing Bangla news data for model training.  
2. **Model Fine-Tuning:** Leveraging transformer models for accurate text classification.  
3. **Evaluation:** Assessing performance using multiple metrics to ensure reliability.  
4. **Experimentation:** Jupyter Notebook implementation allows easy testing and reproducibility.

This project demonstrates the effectiveness of modern **deep learning techniques** in addressing **real-world misinformation challenges** in low-resource language settings.
